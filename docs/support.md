# TripDocket support

For reproducible app problems use https://github.com/4alvit/travel-documents-ios/issues.
Include the version, device/OS and
steps with fictional data. Never attach passports, tickets, purchase receipts
from StoreKit, or personal backups.

If a file is not ready offline, open it in Files and finish its download before
importing. A thumbnail is not proof that the original is present. If a stored
original is damaged, keep a copy of the library and recover from a known-good
backup; do not delete the app as a troubleshooting step without a backup.

For missing Pro use Restore Purchases under the same App Store account. This
does not restore documents. This preview's StoreKit configuration creates test
transactions only. Live products and App Store distribution are not configured.

To import several documents with Pro, open a trip's actions menu and choose
Import multiple files. Select no more than 10, open each row, check the original
and confirm its details, then save the batch. Editing a confirmed field requires
confirmation again. If preparation fails, no part of the selection is added;
correct the file or choose fewer files and retry. Cancel discards the unsaved
draft. Keep the app running until Save finishes; quitting loses unsaved drafts.
