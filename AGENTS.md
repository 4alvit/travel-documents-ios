# Travel Documents

Original native iOS app. Use only synthetic documents, names and screenshots.
No credentials, user documents, private paths, Terraform state or harness traces
belong in this public repository. Infrastructure is managed separately.

SwiftUI app and a Foundation/CryptoKit domain package. Avoid third-party runtime
dependencies. Preserve offline access, viewing, export and recovery regardless
of Pro entitlement. Never share automatically. App lock uses device authentication;
do not invent a cryptographic protocol. Exported backups are portable plaintext
containers and require an explicit warning and user-selected destination.

Read docs/implementation-contract.md before implementing parallel tasks. Never
overwrite another contributor's changes. Test storage transactions, restore
validation, complete-original verification, and license transitions. Marketing
must distinguish verified checks from planned features and App Store publication.
