# Security

Do not put passport scans, tickets, account identifiers or security exploit
details in a public issue. Use the repository's private vulnerability reporting
interface when enabled: https://github.com/4alvit/travel-documents-ios/security/advisories/new

This development preview has no security certification. Device authentication,
Apple data protection and the application sandbox are its security boundary.
Exported packets are not encrypted. See docs/data-and-recovery.md for limits.

Include the version/commit, device/OS, a minimal synthetic reproduction and the
expected versus actual behavior. Report original-data loss, restore replacement,
plaintext leakage, lock bypass and entitlement issues as separate findings.
